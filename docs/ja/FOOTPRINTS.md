# SnippetFlow (SnippetManager) パフォーマンス・フットプリント計測記録

本ドキュメントでは、アプリケーションのフットプリント（実行バイナリサイズ、CPU/メモリリソース使用量）の計測結果を記録します。

---

## 1. ビルドプロファイルとバイナリサイズ

リリースビルドで生成されたバイナリサイズおよび最適化フラグの構成を記録します。
* **ビルドコマンド**: `npm run tauri build`
* **生成バイナリ**: `src-tauri/target/release/Snippetflow.exe`
* **バイナリサイズ**: **約 2.6 MB** (最適化済みネイティブ実行バイナリ)
* **インストーラー (.msi / .exe)**: **約 4〜5 MB** (Webview2ランタイムを同梱せずシステム共有するため超軽量)


---

## 2. メモリフットプリント (RAM)

Windowsのタスクマネージャー、またはリソースモニターによる常時稼働時のメモリ使用量（Tauri Rustバックエンド本体）です。
※ UI設定（テーマ・ソート順）は WebView2 側の `localStorage` に保持されるため、Rust 側の追加メモリ消費はありません。

| 動作状態                                | メモリ使用量 (実物理メモリ/Working Set) | 備考                                                                |
| :-------------------------------------- | :-------------------------------------- | :------------------------------------------------------------------ |
| **起動直後 (アイドル状態)**             | **約 12.7 MB** (Private: 約 8.4 MB)     | Rust バックエンドと暗号化 JSON ファイルの初期ロードを伴います。     |
| **検索・閲覧中 (アクティブ状態)**       | **約 12.7 〜 13.2 MB**                  | IPC 経由のインクリメンタルフィルタリング・ソート処理がかかります。  |
| **スニペット新規追加 (フォーム入力中)** | **約 12.7 〜 13.2 MB**                  | キーワードの出現頻度分析およびタグ推薦計算が走ります。              |

---

## 3. CPU使用率

* **アイドル状態**: **0%**
  - イベント駆動（IPC呼び出し時のみ実行）アーキテクチャのため、待機中のCPUスパイクは発生しません。
* **アクティブ状態 (ユーザー入力・連続コピー等)**: **0.1% 〜 1.0%**
  - キーボード入力やクリックなどのイベント駆動時のみCPUが一時的に動作します。

---

## 4. ビルド最適化オプション (適用済み)

バイナリサイズを削減し、実行パフォーマンスを最適化するためにワークスペースルートの `Cargo.toml` に適用した設定プロファイルです。

```toml
[profile.release]
opt-level = "z"      # サイズ最優先の最適化
lto = true           # Link-Time Optimization の有効化
codegen-units = 1    # コードジェネレータのユニット数を1にして最適化を保護
panic = "abort"      # パニック時の巻き戻しコードを除外してサイズ削減
strip = true         # デバッグシンボルとシンボルテーブルの自動削除
```
